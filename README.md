# Shopping Website

This is a simple shopping website built with **HTML**, **CSS**, and **JavaScript**. It features product listings, a shopping cart, and basic user interaction.

## Features

- **Product Display**: Displays products with images, descriptions, and prices.
- **Add to Cart**: Allows users to add items to their shopping cart.
- **Cart Management**: Users can remove items from the cart and view the total price.
- **Responsive Design**: The website adapts to both desktop and mobile screens.

## Technologies Used

- **HTML**: Provides the structure and content of the website.
- **CSS**: Used to style and layout the website, making it responsive and user-friendly.
- **JavaScript**: Handles interactivity, such as adding/removing items from the cart and calculating the total price.

## Usage

- **View Products**: The homepage displays products with their images, descriptions, and prices.
- **Add to Cart**: Click the **"Add to Cart"** button next to any product to add it to the shopping cart.
- **View Cart**: You can view the cart by clicking the shopping cart icon in the top-right corner of the page.
- **Remove Items from Cart**: In the cart, you can remove products by clicking the **"Remove"** button next to each item.
- **Checkout**: The total price is automatically updated in the cart.
